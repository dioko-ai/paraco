# Contributing to Paraco

Please keep changes small, testable, and aligned with the local-first runtime
contract. Run `cargo fmt --check`, `cargo test`, and
`node --test tests/management.test.cjs` before submitting a change. New public
contracts need matching documentation, runtime validation, and tests.

Do not include credentials, tokens, or private production data in issues,
commits, fixtures, or logs. Contributions are submitted under the Apache-2.0
license in this repository.
